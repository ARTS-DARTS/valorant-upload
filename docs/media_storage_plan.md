# План хранения медиа VLineups

Зафиксированное направление после восстановления файлов из Cloudinary:

- основное объектное хранилище — Cloudflare R2;
- публичная раздача — через собственный адрес `media.vlineups.ru`;
- в Firestore хранится наш стабильный URL и метаданные файла, а не адрес стороннего провайдера;
- оригиналы дополнительно копируются на VPS или локальный резервный диск;
- переключение старых ссылок выполняется только после загрузки и проверки файла;
- для каждого объекта сохраняются владелец, размер, MIME-тип, хеш и состояние миграции;
- фотографии оптимизируются для показа, но оригинал не уничтожается.

Cloudflare R2 выбран из-за бесплатного лимита 10 GB-month, бесплатного исходящего трафика и S3-совместимого API. Перед включением необходимо проверить фактический размер восстановленного архива и условия регистрации R2 для владельца аккаунта.
